## About

I'm Nandini MAvillapalle an **M.Sc. candidate in Electronics Engineering** at Hochschule Bremen, focused on the layer where **Embedded software** — turning raw sensor signals into reliable, quantified insight on real-time hardware.

My work centers on **digital signal processing, embedded firmware, and metrology**: extracting meaning from noisy data, characterizing systems with rigorous uncertainty analysis, and running DSP pipelines on constrained microcontrollers. I approach engineering with a **measurement-first mindset** — every result comes with a traceable method and an error bar, not just a number.

I'm currently building **automotive-grade embedded skills** in C and real-time DSP, complementing a strong foundation in Python-based signal analysis and the GUM measurement-uncertainty framework.

**Open to:** `Werkstudent` · `Praktikum` · `Internship` — Automotive Embedded Software Engineering (Germany)

## Featured Projects

<details open>
<summary><b>Cantilever Vibration Analysis — Python Signal-Processing Pipeline</b></summary>

<br/>

End-to-end analysis of real cantilever ring-down data captured on a PicoScope, extracting modal parameters from raw acquisition through to publication-quality results.

| Attribute | Detail |
|:----------|:-------|
| **Stack** | Python · NumPy · SciPy · Matplotlib · Jupyter · PicoScope |
| **Method** | Hann-windowed FFT → parabolic peak refinement log-decrement → Q-factor |
| **Results** | Resonant f ≈ 476 Hz (unloaded), ≈ 290 Hz (tip mass); ζ ≈ 0.0019–0.0049; Q ≈ 103–265 |
| **Rigor** | Consistent Q ≈ 167 ± 5 across valid datasets; clipped runs identified and excluded |
| **Deliverable** | Full LaTeX analysis section with TikZ flowchart, booktabs tables, six figures |
| **Repository** | [`Cantiliver_Project`](https://github.com/mavillapalle/Cantiliver_Project) |

A complete data-acquisition-to-report pipeline demonstrating rigorous, reproducible signal analysis on real experimental data.

</details>
